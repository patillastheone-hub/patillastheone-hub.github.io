1. Responsable

El responsable de esta aplicación y del tratamiento de los datos descritos aquí es el propietario del canal de YouTube La Bóveda | Los Mejores Clips (@boveda.clips_es), que actúa como particular. Contacto: patillastheone@gmail.com.

2. Qué es esta aplicación

«Bot de publicación» es un programa de escritorio de uso personal que se ejecuta en el ordenador de su propietario. No es un servicio abierto al público: no admite registro, no tiene cuentas de usuario y nadie más que su propietario puede utilizarla.

3. Qué datos se tratan

La aplicación accede únicamente a la cuenta de Google y al canal de YouTube de su propio propietario, y solo a lo siguiente:

  • Datos del canal (nombre, identificador, número de suscriptores y vídeos): para mostrarlos en el panel privado del propietario y comprobar que la conexión funciona.
  • Vídeos y sus metadatos (título, descripción, etiquetas, miniatura, subtítulos, listas de reproducción): para subir y organizar los vídeos del propio propietario.
  • Estadísticas del canal (visualizaciones, tiempo de visualización, retención, suscriptores ganados): para elaborar informes privados que solo ve el propietario.
  • Credenciales de acceso (tokens de OAuth 2.0 emitidos por Google): para poder hacer lo anterior sin volver a iniciar sesión cada vez.

No se trata ningún dato de terceros. La aplicación no accede a canales, vídeos, comentarios ni cuentas que no sean los de su propietario, ni recoge información de las personas que ven los vídeos más allá de las estadísticas agregadas y anónimas que ofrece la propia YouTube Analytics API.

4. Permisos que se solicitan y para qué

  • youtube.upload — subir vídeos al canal del propietario.
  • youtube.force-ssl — leer los datos del canal, editar títulos y descripciones y gestionar listas de reproducción y subtítulos de esos mismos vídeos.
  • yt-analytics.readonly — leer, solo en modo lectura, las estadísticas del canal.

5. Dónde se guardan los datos

Todos los datos se guardan en local, en el ordenador personal del propietario: los tokens de acceso en un archivo del propio equipo y las estadísticas en una base de datos local. No hay servidores propios, ni copias en la nube gestionadas por esta aplicación, ni bases de datos accesibles desde internet.

6. Con quién se comparten

Con nadie. Los datos no se venden, no se ceden, no se comparten con terceros, no se usan para publicidad y no se emplean para entrenar modelos de inteligencia artificial. La única comunicación externa de la aplicación es con las APIs de Google y YouTube, y con los servicios necesarios para producir los vídeos, a los que nunca se envían datos personales de la cuenta.

7. Cuánto tiempo se conservan

Los tokens se conservan mientras la autorización siga activa y se borran del equipo cuando se revoca. Las estadísticas descargadas se conservan en local mientras le resulten útiles al propietario, que puede eliminarlas en cualquier momento borrando el archivo correspondiente.

8. Cómo revocar el acceso

El propietario puede retirar en cualquier momento el permiso concedido a esta aplicación desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de tener acceso a la cuenta de forma inmediata.

9. Servicios de la API de YouTube

Esta aplicación utiliza los Servicios de la API de YouTube. Al usarla, su propietario queda sujeto a las Condiciones del Servicio de YouTube, y el tratamiento que Google hace de los datos se rige por la Política de Privacidad de Google.

10. Esta página web

Esta página es estática y está alojada en GitHub Pages. No usa cookies, no incorpora analítica ni rastreadores y no recoge ningún dato de quien la visita, más allá de los registros técnicos que el propio proveedor de alojamiento pueda generar.

11. Cambios en esta política

Si la aplicación cambia lo que hace con los datos, esta página se actualizará y se modificará la fecha de arriba.

12. Contacto

Para cualquier duda sobre esta política: patillastheone@gmail.com.

English version

Who. The owner of the YouTube channel La Bóveda | Los Mejores Clips (@boveda.clips_es), acting as a private individual. Contact: patillastheone@gmail.com.

What the application is. "Bot de publicación" is a personal desktop application that runs on its owner's own computer. It is not a public service: there is no sign-up, there are no user accounts, and nobody other than the owner can use it.

What data it handles. Only the owner's own Google account and YouTube channel: channel details, the owner's own videos and their metadata, the channel's own statistics and retention, and the OAuth 2.0 tokens issued by Google. It requests the scopes youtube.upload, youtube.force-ssl and yt-analytics.readonly, used strictly for uploading and managing the owner's own videos and for reading the owner's own statistics. No third-party data is processed, and no information is collected about viewers beyond the aggregated, anonymous figures provided by the YouTube Analytics API itself.

Where it is stored. Everything is stored locally on the owner's computer: access tokens in a local file, statistics in a local database. There are no servers, no cloud copies managed by this application and no internet-accessible databases.

Sharing. None. Data is never sold, shared, used for advertising or used to train AI models. The only external communication is with Google and YouTube APIs and with the services needed to produce the videos, which never receive personal account data.

Retention and revocation. Tokens are kept while the authorisation is active and are deleted when it is revoked. The owner can revoke access at any time at myaccount.google.com/permissions.

YouTube API Services. This application uses YouTube API Services. Its use is subject to the YouTube Terms of Service, and Google's handling of data is governed by the Google Privacy Policy.

This website. Static page hosted on GitHub Pages. No cookies, no analytics, no trackers, no data collected from visitors.
